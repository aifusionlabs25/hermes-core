# X Agents Pilot Economics and SOP

Status: draft for Rob review.
Created: 2026-05-21.

## Purpose

Define a simple operating model for selling low-cost X Agents pilots while controlling provider-minute risk.

## Core Model

Sell small monthly pilot subscriptions with included minute allowances.

Profit comes from:

- setup fees
- monthly recurring revenue
- low average usage
- controlled support scope
- upgrades for clients who need more

## Unit Economics Template

Track each client:

| Field | Meaning |
| --- | --- |
| Client | Business name |
| Tier | Lite / Pro / Custom |
| Setup fee | One-time fee |
| Monthly price | Subscription |
| Included minutes | Monthly included allowance |
| Actual minutes | Monthly usage |
| Provider cost/min | Real cost |
| Estimated provider cost | Actual minutes times cost/min |
| Gross margin before labor | Monthly price minus provider cost |
| Rob support time | Hours spent |
| Status | trial / active / upgrade / cancel |

## Example Pricing Scenarios

These are draft scenarios, not final pricing.

- target use: simple website lead capture

### Lite Balanced

- setup: $299

- target use: most first pilots

### Lite Strong

- setup: $499
- monthly: $199
- included: 60 minutes
- target use: better businesses with obvious missed-call value

## Usage Guardrails

Rules:

- no unlimited minutes
- no hidden overage surprises
- alert at 80 percent usage
- require approval or upgrade at 100 percent usage
- review usage weekly during first 30 days
- do not add high-volume clients to Lite without Pro pricing

## Pilot Lifecycle

### Stage 1: Research

Input:

- public website
- public contact details
- business category
- website lead-capture review

Output:

- lead score
- recommended offer angle
- Rob approval status

### Stage 2: Outreach Draft

Output:

- short email
- short call script
- one-line value prop
- reason this business is a fit

Rob approval required before sending.

### Stage 3: Discovery Call

Goal:

- learn lead flow
- confirm pain
- confirm approval path
- confirm whether Lite is enough

Do not oversell. If they need CRM, SMS, or booking, mark as Pro/Custom.

### Stage 4: Pilot Setup

Checklist:

- business FAQ
- services list
- service area
- contact rules
- escalation rules
- lead capture fields
- approved fallback language
- notification email
- usage allowance
- pilot start/end date

### Stage 5: Weekly Review

Track:

- conversations
- leads captured
- minutes used
- common questions
- owner feedback
- issues
- upgrade opportunities

### Stage 6: 30-Day Review

Decision:

- continue
- upgrade
- revise
- pause/cancel

## SOP: Daily GTM Work

Daily 30-minute operating loop:

1. Add 10 new leads.
2. Score each lead.
3. Pick top 3.
4. Draft outreach for top 3.
5. Ask Rob to approve or reject.
6. Track results in lead sheet.

## SOP: Weekly Revenue Review

Review:

- leads researched
- outreach sent
- replies
- booked calls
- pilots offered
- pilots sold
- monthly recurring revenue
- provider minutes used
- support time
- top objections
- needed X-LINK work orders

## X-LINK Feedback Loop

Create proposed X-LINK work orders only when market signals repeat.

Examples:

- multiple businesses ask for SMS follow-up
- multiple businesses need quote intake
- multiple businesses ask about calendar booking
- demo repeatedly fails at the same provider step
- lead summaries are not useful enough

Work orders remain drafts until Rob approves.

## Stop Conditions

Pause the Lite offer if:

- provider costs exceed monthly revenue
- setup takes more than 3 hours per Lite client
- clients need custom work but pay Lite pricing
- demo reliability is poor
- Rob must manually rescue every lead
